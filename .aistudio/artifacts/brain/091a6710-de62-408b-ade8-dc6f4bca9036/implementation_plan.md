# Glyph Oracle — Оптимизация UX/UI, логики настроек и валидации API-ключей

Комплексное обновление интерфейса и пользовательских сценариев **Glyph Oracle** для устранения визуального шума, дублирующихся надписей и нелогичных состояний элементов управления до ввода API-ключа.

## User Review & Critical Decisions

> [!IMPORTANT]
> Все ключевые решения согласованы на основе ваших ответов и требований:

- **Поведение кнопок API до ввода ключа**: Кнопки **«Модели из API»** и **«Тест API»** блокируются (`enabled = false`), пока поле API-ключа для выбранного провайдера пустое, при этом базовый список предустановленных моделей остаётся доступным для выбора.
- **Структура экрана настроек**: Вместо разрозненных мелких карточек экран настроек объединяется в **две логические карточки**:
  1. **Язык и ИИ-провайдер** (выбор языка в самом верху + настройка провайдера, ключа, Base URL и модели).
  2. **Общие параметры** (системный промпт, лимит слов, режим захвата голоса, окно паузы, яркость матрицы и скорость бегущей строки).
- **Блокировка главного экрана без API-ключа**: Если для текущего провайдера не введён API-ключ, кнопка голосового вопроса, текстовое поле и кнопка отправки блокируются (`enabled = false`), а над ними отображается заметная плашка с кнопкой быстрого перехода к вводу API-ключа.

## 1. Overview & Core Concept

- **What It Does**: Приводит пользовательский путь от первого запуска до голосового/текстового запроса в строгий логический порядок: приложение автоматически определяет язык системы при первом запуске, сразу показывает переключатель языка в начале настроек, требует ввода API-ключа перед активацией запросов и тестирования, а также избавляется от лишних повторов `25×25` и технических ярлыков.
- **Target Audience / Persona**: Владельцы Nothing Phone (3), которым нужен чистый, продуманный и отзывчивый интерфейс в фирменной эстетике Nothing OS без визуального мусора и ложных срабатываний.
- **Key Value**: Исключение ошибок при попытке отправить запрос или загрузить модели без ключа, единый порядок полей для всех 6 провайдеров и компактная группировка настроек.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **Первый запуск и автоопределение языка**: При отсутствии сохранённой настройки языка приложение проверяет системную локаль устройства (`Locale.getDefault().language`): если язык системы русский (`ru`), интерфейс и системный промпт по умолчанию включаются на русском; иначе — на английском. Пользователь также может явно выбрать `Авто (Системный)`, `Русский (RU)` или `English (EN)` в самом верху вкладки настроек.
  2. **Защита от запросов без API-ключа на главном экране**: Пока для активного провайдера не задан ключ, кнопка записи голоса и поле текстового ввода неактивны (`enabled = false`), а в блоке статуса выводится предупреждение с кнопкой **«Ввести API-ключ»**, переключающей на вкладку настроек.
  3. **Единый порядок настройки любого провайдера**: При выборе любого из 6 провайдеров (включая `OpenAI-Совм.`) первым полем всегда идёт **API-ключ**, затем (только для `OpenAI-Совм.`) — **Base URL и пресеты серверов**, и далее — **Выбор/добавление модели** и кнопки **«Модели из API»** / **«Тест API»** (активные только при наличии ключа).
- **Visual Identity & Theme**:
  - *Aesthetic Direction*: Индустриальный минимализм Nothing OS — монохромная база с точечными акцентами `NothingRed` (`#D71921`), `NothingGreen` (`#00E676`) и `NothingAmber` (`#FFB300`).
  - *Чистка заголовков и бейджей*:
    - Из верхней панели (`TopBar`) полностью удаляется бейдж `SDK v1.1`.
    - Убираются дублирования `25×25` из подзаголовка шапки, нижней навигации (`МАТРИЦА` вместо `МАТРИЦА 25×25`), статусных пилюль (` ГОТОВ` / `СТАТИКА` / `БЕГУЩАЯ СТРОКА` вместо `IDLE • 25×25` / `СТАТИКА 25×25`), заголовков карточек и карточек истории (`ОТВЕТ:` вместо `ОТВЕТ 25×25:`). Обозначение `25×25` остаётся только один раз — в заголовке самого визуализатора матрицы.
    - Кнопка проверки переименовывается из `ТЕСТ API (2+2)` в лаконичное **`ТЕСТ API`** (`TEST API`).

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: Автоопределение языка системы + перенос выбора языка в начало настроек**
  - *Chosen Approach*: Инициализация языка по `Locale.getDefault()` при первом запуске и размещение селектора языка самым первым элементом на вкладке настроек.
  - *Why*: Пользователь не сталкивается с ситуацией, когда он проходит весь экран настроек на неродном языке и находит переключатель только в самом низу.
- **Decision 2: Консолидация настроек в 2 карточки вместо 4**
  - *Chosen Approach*: Объединение настроек промпта, голоса и матрицы в единую карточку **«Общие параметры»** с аккуратными внутренними разделителями (`HorizontalDivider`).
  - *Why*: Избавляет от карточек-категорий с одной-двумя настройками и уменьшает вертикальную прокрутку.
- **Decision 3: Реактивная блокировка элементов без API-ключа**
  - *Chosen Approach*: Вычисление флага `hasApiKey = settings.getResolvedApiKey().isNotBlank()` и передача его в `enabled` для кнопок записи голоса, отправки текста, `Модели из API` и `Тест API`.
  - *Why*: Предотвращает заведомо неуспешные сетевые вызовы и сразу объясняет пользователю, что нужно сделать для начала работы.

### Interactive Component & State Mapping

1. **Автоопределение языка**:
   - Если в `SharedPreferences` ключ `speech_language` ещё не сохранён, `OracleSettingsRepository` проверяет `Locale.getDefault().language`: для `"ru"` устанавливается `"ru-RU"`, для остальных языков — `"en-US"`.
   - В начале `AiSettingsScreen` отображается переключатель языка (`Русский` / `English` + кнопка `Авто` по системному языку).
2. **Порядок полей и блокировка кнопок в Карточке 1 (`AiSettingsScreen`)**:
   - Поле ввода **API-ключа** рендерится сразу под сеткой выбора провайдера для всех 6 провайдеров.
   - Поле **Base URL** и чипы пресетов для `CUSTOM_OPENAI` размещаются *после* поля API-ключа.
   - Кнопки **«Модели из API»** и **«Тест API»** получают `enabled = resolvedKey.isNotBlank() && !isFetchingModels`. Под списком базовых моделей при отсутствии ключа выводится ненавязчивая подсказка, что для подгрузки дополнительных моделей с сервера нужен ключ.
3. **Блокировка управления на главном экране (`MatrixControlScreen`)**:
   - Если `hasKey == false`, поверх блока ввода отображается карточка-подсказка с кнопкой перехода к вводу ключа (`onOpenAiSettings`), а кнопка записи голоса, текстовое поле и кнопка отправки переводятся в состояние `enabled = false`.
